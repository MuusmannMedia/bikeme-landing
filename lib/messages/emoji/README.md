# Unicode emoji data

Vendored data, not a runtime package or service. Unicode Emoji **15.1**, CLDR **46**. Generated by `python3 scripts/generate-emoji-catalog.py` from the pinned, SHA256-verified inputs in scripts/emoji-source. Running twice produces identical output. See manifest.json for source URLs, hashes, counts and coverage.

catalog.json contains all 3,773 fully-qualified entries, excluding standalone components. aliases.json maps the 5,025 official fully/minimally/unqualified forms to canonical fully-qualified sequences; it is used to build the server validation tables and is not imported by the UI. Each language has 3,773 labels and search keywords. Danish territory/keycap names missing from CLDR derived annotations use Danish territory names plus Danish flag/keycap labels; England/Scotland/Wales have explicit Danish names. No English fallback is used for the seven supported languages.

The UI uses device emoji fonts and lazily loads the selected language when the full palette opens. Search is local. Newer Unicode versions and non-RGI/invented sequences are not supported by this catalog. Glyph rendering depends on the OS font. Skin-tone modifiers alone, partial flags, plain text, multiple emoji, VS15 text-presentation forms and redundant selector forms absent from the official data are rejected. Supported VS16 qualification aliases canonicalize to the same reaction.

LICENSE contains the Unicode License V3. license.json carries the same notice and emoji copyright into the JS bundle; the local Hermes export was checked for it. Original source notices are retained. No npm dependency, bitmap sprite, network picker or native module was added.

Sources: [Emoji 15.1](https://www.unicode.org/Public/emoji/15.1/emoji-test.txt), [CLDR release 46](https://github.com/unicode-org/cldr/tree/release-46), [Unicode license](https://github.com/unicode-org/cldr/blob/release-46/LICENSE).
